Перед началом работы необходимо подтягивать актуальные изменения для решения конфликтов!
git fetch - скачать актуальные изменения
git rebase origin/main - применение изменений поверх своих
После чего необходимо создать свою ветку для работы от develop
Например features/auth
После окончания работы над фичей заливаем изменения 
git push
